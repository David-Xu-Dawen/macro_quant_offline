# Macro Quant 使用说明

这是一个**本地宏观看板**。你从万得（Wind）导出一张 Excel，放到这个文件夹里，跑一条命令，电脑就会算出：

1. 现在增长、通胀、利率、信用、汇率、地缘大概处在什么位置；
2. 这些东西彼此是一起走，还是对着走；
3. 股票、债券、黄金、原油更吃哪一类宏观冲击；
4. （可选）一个自动给出的稳健 / 均衡 / 进取配置建议。

**它不会自己去网上拉数据。** 数据只能你从 Wind 导出。算完之后用浏览器打开一个本地网页看图，不需要再开任何网站账号。

下面按「先会用、再看懂」来写。专有名词第一次出现都会用大白话解释。

---

## 0. 你需要准备什么

- 一台电脑（Windows 或 Mac 都可以）
- 已经安装好 **Python**（Windows 上如果装了 Anaconda，打开「Anaconda Prompt」即可）
- 万得终端，能导出 Excel
- 本项目整个文件夹（GitHub 上下载解压后的那一份）

不需要会写代码。你只要会：把文件改个名、在黑色窗口里复制粘贴一行命令、用浏览器打开一个地址。

---

## 1. 第一次怎么跑起来

请先用资源管理器（或 Mac 的 Finder）打开**本项目最外层那个文件夹**。里面应该能看到 `update_all_data.py`、`README.md`、`requirements.txt`。这个文件夹就叫「项目根目录」。后面所有文件都往这里放。

### 第一步：安装计算用的工具包（只做一次）

打开终端：

- **Windows**：开始菜单搜「Anaconda Prompt」或「命令提示符」，先 `cd` 进项目文件夹，例如：

```bat
cd /d H:\xuwen\Desktop\macro_quant_offline-main
```

- **Mac**：打开「终端」，拖进项目文件夹或输入：

```bash
cd "/Users/你的用户名/Desktop/macro_quant copy"
```

然后安装依赖（只要成功一次，以后不用重复装）：

Windows：

```bat
python -m pip install -r requirements.txt
```

Mac：

```bash
python3 -m pip install -r requirements.txt
```

如果提示 `python: command not found`，改成 `python3`。反过来也一样：Mac 上常常没有 `python` 这个名字。

### 第二步：从 Wind 导出数据，改名叫 data1.xlsx

1. 在 Wind 里按文末清单把指标都加进一张表（日频即可，月度指标空着的日子留空）。
2. 导出为 **Excel（.xlsx）**。如果只能出 `.xls`，用 Excel 打开再「另存为」`.xlsx`。
3. 把文件放到项目根目录，**文件名改成 `data1.xlsx`**，覆盖原来那份。

程序认名字的顺序是：`data1.xlsx` → `data_new.xlsx` → `data.xlsx` → `data.csv`。根目录里只要有 `data1.xlsx`，就永远用它，不会去读旁边的 `data.xlsx`。

如果还想给网页「因子暴露」多加一些资产（行业指数、个股等），另外做一张 **`additional_asset.xlsx`** 放到项目根目录。第一行可以空着，从第二行「指标名称」开始，详见第 10 节。

### 第三步：让电脑重算一遍

还在刚才那个黑色窗口里，输入：

Windows：

```bat
python update_all_data.py
```

Mac：

```bash
python3 update_all_data.py
```

这一步可能要几分钟到十几分钟。屏幕上会依次出现 `[data]`、`[corr]`、`[exposure]`、`[model]`。

- 最后一行出现「全部完成」，就可以去打开网页。
- 如果卡在 `model` 或模型报错：**前面的热力图和暴露其实已经算完了**。想跳过模型、只更新看板，用：

```bat
python update_all_data.py --skip-model
```

（Mac 把 `python` 换成 `python3`。）

### 第四步：打开网页

同一个窗口再输入：

```bat
python3 -m http.server 8765
```

Mac 用 `python3 -m http.server 8765`。这行命令会一直占着窗口，不要关。然后用 Chrome / Edge 打开：

<http://127.0.0.1:8765/macro_factor_corr_interactive.html>

换过新的 Excel 再算完，请**强制刷新**网页，否则浏览器可能还显示旧图：

- Windows：`Ctrl + F5`
- Mac：`Command + Shift + R`

看完后，在黑色窗口里按 `Ctrl + C` 可以停掉本地网页服务。

## 2. 这个项目在干什么（一张图）

```text
你：Wind 里导出 data1.xlsx（原始数字：股价、PMI、金价……）
        ↓
电脑：update_all_data.py
        ↓
    ① 把原始数字合成「宏观因子」（增长、通胀……）
    ② 算因子之间像不像（相关矩阵，就是那些红绿格子）
    ③ 算股票/债券对因子有多敏感（因子暴露）
    ④ （可选）训练一个配置模型
        ↓
你：浏览器里看图
```

记住三句话：

1. **Excel 是原料**，里面是 Wind 的原始指标。  
2. **因子是炒好的菜**，把很多原始指标按固定菜谱合成一列「增长」「通胀」等。  
3. **网页是端上桌的盘子**。只换 Excel、不跑命令，盘子里还是昨天的菜。

## 3. 几个必须先懂的词

**低频 / 高频**  
低频 = 一个月看一个点，适合讲「这个季度宏观环境」。高频 = 一周（或每天）看一个点，适合讲「这周市场在抢跑什么」。同一个因子有两条线，不是两套完全无关的理论。

**同比**  
和去年同一个月比。CPI 同比 2% 表示物价比去年这个月贵了 2%。

**水平**  
就是数字本身，不再减去年。十年国债收益率 2.1%、美元指数 104、GPR 指数 80，都是水平。

**相关（格子里的 −1 到 1）**  
两个因子 historically 是否一起动：

- 接近 **1**：经常同涨同跌  
- 接近 **0**：没什么关系  
- 接近 **−1**：经常对着走  

格子颜色越红通常正相关越强，越绿负相关越强（对角线永远是 1，因为自己和自己完全相关）。

**暴露**  
回答：「这个宏观因子往上走一截时，这个资产的周收益通常往哪边、有多明显」。正数 = 同向，负数 = 反向。例如国债对利率因子接近 −1，意思是利率起来时国债价格往往跌。

**滞后**  
有的市场价会提前几个月动。高频增长里「恒生滞后 3 个月」的意思是：用大约 3 个月前的恒生涨跌，去对应现在的增长因子。

## 4. 网页上每一块怎么看

打开页面后，从上到下大致是：

**左边大方块：月频热力图（低频）**  
六个宏观因子每个月一个数，从 2021 年到现在，两两算相关。用来想「配置故事」：比如增长和汇率长期是不是对着走。

**右边大方块：周频热力图（高频）**  
同样六个名字，但是用周频的合成线。用来想「交易/战术」：这周市场定价的宏观，和月度官方数据是不是一回事。

**点开非对角线的一个格子**  
会展开这对因子的说明：投资上怎么理解、能不能对冲。

**因子暴露矩阵**  
行是资产（上证50、国债、黄金……），列是因子（增长、通胀、利率……还有一个流动性）。格子里是暴露系数。最右边一列 **R方** 可以粗浅理解成「这些宏观因子合在一起，能解释这个资产周涨跌的百分之多少」。现在用的是普通最小二乘（OLS）那个更高的数字；格子里的系数仍是比较稳的 Lasso。不是考试分数，也不是保证未来还能解释这么多。个股（自己加的股票）R方很低是正常的。

**波动警报**  
看最近一周宏观冲击大不大（和自己的历史比，处在什么分位），以及哪些资产可能更难受。这里用的是「这一周变了多少」，不是热力图里那种「现在的绝对水平有多高」。

**最下面的模型预测**  
稳健 / 均衡 / 进取三套权重和历史回测图。这一块依赖最后的模型训练；你用 `--skip-model` 时，这里可能还是旧图。

为什么热力图和暴露对不上？  
因为问的问题不同：热力图看「两条线长得像不像」；暴露看「资产收益对因子的**变化**有多敏感」。利率热力图用收益率的绝对水平，暴露却用「这周利率变了多少」。

## 5. 七个因子分别是什么

一共 6 个会出现在红绿热力图里，外加 1 个**只出现在暴露里**的流动性。每个都有低频、高频。

下面每个因子都按同一结构写：**人话 → 低频怎么算 → 高频怎么算 → 数字变大代表什么**。

### 5.1 增长因子
想刻画中国经济活动是在加快还是放慢：工厂景气、投资、消费、外贸。

**低频（一个月一个数）**  
用四样官方月度数据加权：

| 用到的 Wind 指标 | 在菜谱里做什么 | 大约多重 |
|------------------|----------------|----------|
| 中国:制造业PMI | 先取月末值，再减去 12 个月前，得到「比去年热了还是冷了」 | 58% |
| 社会消费品零售总额同比 | 消费快不快 | 25% |
| 出口同比、进口同比平均 | 外贸快不快 | 10% |
| 固定资产投资完成额累计同比 | 投资快不快 | 7% |

权重是以前回归留下来的，不会每次重算时乱改。某个月缺一两项（比如年初还没有 PMI 同比差），就用剩下至少两项把权重重新按比例摊开。热力图用的是加权后的 `raw_growth_factor`。

中国 1、2 月社零和固投经常空一个月，程序会用前后月大致补上，避免每年年初一个大洞。

**高频（尽量天天/周周有）**  
官方 PMI 一个月才出一次，市场会提前在股价和商品里反应。所以用三样天天有报价的东西去「模仿」上面那条月度增长：

| 代理 | 通俗理解 | 滞后 | 权重 |
|------|----------|------|------|
| LME 三个月铜 | 全球工业需求，权最大 | 0 | +77% |
| 申万房地产指数 | 国内地产景气 | 约 1 个月 | −15% |
| 恒生指数 | 离岸风险偏好/增长预期 | 约 3 个月 | −8% |

做法：每天算这三样的涨跌幅（对数收益），按上表错位、加权，再像净值一样累加起来，最后再算一个「和一年前比涨了多少」。热力图用这个同比；暴露用「这一周累加了多少日涨跌」。

**数字变大** = 增长在加快（或市场在交易加快）。

---

### 5.2 通胀因子

消费品价格和生产品价格是不是在往上走。

**低频**  
CPI 当月同比、PPI 当月同比。谁最近一年晃得更厉害，权重就自动小一点（「波动率倒数加权」），避免一条特别吵的线把因子带跑。刚开始样本不够时就各 50%。

**高频**  
CPI/PPI 也是月频。市场更早在猪肉、原油、钢材上反应：

| 代理 | 滞后 | 权重 |
|------|------|------|
| 猪肉批发价 | 0 | 约 20% |
| 布伦特原油 | 约 1 个月 | 约 40% |
| 螺纹钢 | 约 3 个月 | 约 40% |

每周五收盘价算一周涨跌，加权后再累加成一条「假的通胀指数」，并计算同比。热力图看同比；暴露看这一周涨了多少（`hf_wow`）。

**数字变大** = 通胀压力上升。

---

### 5.3 利率因子

中国长期利率高不高。主要看十年期国债收益率。

**低频**  
「中债国债到期收益率:10年」每个月最后一个有数字的交易日。2.8 就是 2.8%，不再做同比。

**高频**  
债券价格和收益率对着走：利率涨，债券净价跌。所以用「中债国债总净价指数」再乘 −1。净价指数往上（债牛），利率因子往下。

暴露不看净价有多高，而看**这一周净价跌了多少**（跌得越多，利率因子这周升得越多）。

**数字变大** = 利率水平更高 / 这周利率在往上。

---

### 5.4 信用因子

信用债比利率债要多给多少利息。利差大 = 市场更担心企业还不起钱。

**低频**  
`AA 级中短期票据 3 年收益率 − 国开债 3 年收益率`  
国开债近似「准利率债」，AA 中票代表中等信用。两者相减就是信用利差。

**高频**  
日频没有那么干净的收益率利差时，改用财富指数：企业债 3–5 年财富指数减去国开 3–5 年财富指数。这个差额里有长期慢慢爬的趋势，程序会去掉慢趋势（HP 滤波，可理解成「把长期斜坡削平，只留绕着走的波动」），再取反、标准化成一条指数。信用变差时这条指数往上。

热力图看周末的指数水平；暴露看指数这周涨了还是跌了。

**数字变大** = 信用变差（利差走阔），不是「信用越好」。

---

### 5.5 汇率因子

全球美元指数（DXY）高不高。美元强，通常对应人民币资产承压、大宗商品也常受压。

**低频和高频是同一条美元指数**，只是取样不同：月末收盘 vs 每周五收盘。没有再造一个「人民币因子」。暴露矩阵里的「美元兑人民币」是被解释的资产，不是这个因子本身。

暴露用「这周美元指数涨了百分之几」。

**数字变大** = 美元更强。

---

### 5.6 地缘因子

报纸上地缘冲突、战争风险热不热。低频直接用公开的 GPR（Geopolitical Risk，地缘政治风险）指数月末值，比如这个月 80、下个月 150。

**低频**  
Wind 里的「全球:地缘政治风险指数」或「……(参考十家报纸)」，取月末最后一个数。**不是**金价、油价。

**高频**  
GPR 更新慢，所以用天天有报价的黄金、原油价格去贴这条指数：

```text
拟合出来的地缘 ≈ 一个常数 + 系数×金价 + 系数×油价
```

金可以错后几个月（程序会在 0～3 个月里选拟合最好的）。油通常不过夜。当前这套数据里，油的权重大、金很小；拟合优度（R²）大约只有 0.2，意思是「金油贵」和「GPR 指数高」只是有点像，不是锁死的。GPR 往往会突然跳到 400+，金油走得平滑得多，所以两条线不必一起高、一起低。

沪金、布伦特原油**会进入**地缘因子的暴露回归。信用因子仍然只解释债券：股票、商品、黄金、原油、美元兑人民币的信用格不参与回归，格子里是 0。

**数字变大** = 地缘风险更高（或金油价格组合显示风险更高）。

---

### 5.7 流动性因子（钱松不松）——只出现在暴露里
 
广义货币（M2）增得快，还是实体融资（社融）增得快。两者之差常被用来看「钱有没有淤在金融体系里」。

**低频**  
`M2 同比 − 社会融资规模存量同比`。

**高频**  
M2/社融也是月频。用申万大盘、小盘的市盈率每天的变化来模仿：大盘 PE 权为负、小盘 PE 权为正，用来捕捉风格和相对流动性。这条线**不进六因子热力图**，只用来解释为什么有时中证 1000 和上证 50 走得不一样。

**数字变大** = 相对流动性更宽（或小盘相对更贵），不要直接理解成「央行放水了」。

---

## 6. 因子暴露是怎么算出来的（可以跳过公式，但建议知道结论）

问的是：过去大约 **5 年（260 周，可在 `panel_config.json` 里改）** 里，每个资产的周涨跌，能被这 7 个宏观因子的「周变化」解释多少。

做法可以想成：

1. 资产：这周涨了还是跌了（用价格算对数收益，和普通涨跌幅很接近）。  
2. 因子：这周宏观冲击是正是负（不是「现在绝对水平有多高」）。  
3. 先把大家放到同一量纲（标准化），再用一种会自动把没用的系数打成 0 的回归（Lasso），避免 7 个因子挤在一起乱解释。  
4. 系数不是只算一次，而是随机抽很多段连续 2 年（104 周）的历史，算 3000 次，取中间那个系数，这样少被某几个极端星期带跑。

**网页最右边的 R方**用的是同一窗口、同一批因子的**普通最小二乘（OLS）**，数字会高一些，表示「这组宏观因子最多能解释多少周收益」。格子里的暴露系数仍然是上面第 4 步的 Lasso 中位数，两者分工不同：系数求稳，R方看解释力。

额外规矩：

- **信用因子**只用来解释国债、企业债、转债。股票、商品的「信用」格子为 0（没进回归）。名字里带「债」「转债」的额外资产也会按债券处理。  
- **地缘因子**也会解释黄金和原油。某个资产不想看某因子，可在 `panel_config.json` 的 `asset_exclude_factors` 里关掉。

12 个默认资产是：上证50、沪深300、中证500、中证1000、恒生指数、中债国债、中债企业债、中证转债、布伦特原油、沪金、标普500、美元兑人民币。还可以用 `additional_asset.xlsx` 往表下面加行，见第 10 节。

### 和旧版项目（macro_quant 0）是不是同一套？

**回归算法是同一套**：周收益、高频因子周变化、标准化 Lasso、260 周、104 周连续块、Bootstrap 3000 次、`alpha_scale=0.5`、信用只进债券。

数字不会和旧版完全一样，常见原因：

- 旧版窗口更长（大约从 **2020 年** 对齐，用过 318 周）；现在 Wind 表大约 **2021 年** 才齐，默认只用最近 **260 周**。  
- 高频因子换成了 Wind 口径（增长、信用、美元指数、金油拟合 GPR 的样本也更短）。  
- 国债、原油的 R方两边都很高（利率、油价几乎就是因子本身）；A 股、标普、黄金往往会低一点；自己加的个股更低，这是正常的。

窗口、看哪些因子、惩罚强弱都可以在 `panel_config.json` 里改，见第 11 节。只重算暴露可以：

```bash
python3 update_all_data.py --only exposure
```

Windows 把 `python3` 换成 `python`。

## 7. 最下面的「模型预测」是什么

这是附加功能，不是看板的核心。

电脑用过去的价格和宏观特征，训练一个排序模型（LightGBM），估计大约 20 个交易日之后哪些资产相对更强，再用一个叫 Black-Litterman 的配置方法把排序变成仓位，给出三档：

- 稳健：更保守  
- 均衡：中间  
- 进取：更敢下重手  

历史回测图只能说明「这套规则在过去模拟中怎样」，**不是对未来收益的保证**。第一次跑会比较慢；日常只更新宏观图时用 `--skip-model` 即可。

## 8. 从 Wind 导出时务必注意

### 文件长什么样

- 第一行（或第二行）左边是「指标名称」，Windows 上 Wind 自己导出时左上角经常是「Wind」，现在两种都能认。  
- 第一列是日期。可以是 `2021-01-04`，也可以是 Excel 里那种一串数字（日期序列号）。  
- 上面可以留着「频率 / 单位 / 指标ID / 来源」这几行，程序会跳过。

### 空着的格子不要填 0

没数就留空。Wind 若设置成「空值显示为 0」，程序会尽量把假 0 当没数：金价、股价、PMI 出现 0 一定当空；CPI 同比偶尔真的是 0.0% 会留下。但最稳妥仍是导出时不要把空值改成 0。

### 列名差一点也能认，但缺列不行

程序先找完全一样的 Wind 全名。对不上时，要求**一组关键词都出现**才认。例如国开 3 年收益率必须同时有「国开债」「到期收益率」「3年」。只写「国开债」不够。名字里多一个 `-`、末尾多一个 `:日` 通常没问题。

如果报 `缺少 国开债_3Y`，就是表里根本没有「中债国开债到期收益率:3年」这根序列，需要回 Wind 补上再导出。

## 9. 算完之后，哪些文件是给人看的

你一般不用打开这些 JSON，网页会自动读。知道它们存在即可：

| 文件 | 对应网页哪一块 |
|------|----------------|
| `macro_factor_corr.json` | 左边月频热力图 |
| `macro_hf_factor_corr.json` | 右边周频热力图和警报 |
| `factor exposure/factor_exposure_latest.json` | 暴露矩阵 |
| `model_prediction_static.json` | 最下面三档模型 |
| `hf_factor_daily.xlsx` | 不进网页。全部高频因子的日频表，工作表 `水平`、`日变化`（单位 %）、`说明`。同内容还有 `hf_factor_daily.csv`、`hf_factor_daily_change.csv`。通胀因子看板里按周算，日频表用同一套猪肉/布油/螺纹钢权重做成日收益，并对齐到最近周五的周频净值 |

真正干活的脚本：

| 文件 | 作用 |
|------|------|
| `update_all_data.py` | 总开关，按顺序调用下面几个 |
| `panel_config.json` | 面板参数，更新前可改 |

## 10. 自己再加资产，并显示在网页的因子暴露里

把额外资产做成**另一张和 data1 一样的 Wind 表**，放到项目根目录，文件名必须是：

- `additional_asset.xlsx`（推荐）
- 或 `additional_asset.csv`

不要写进 `data1.xlsx`。`data1` 继续只放原来那套宏观和 12 个大类资产；你新拉的指数、个股、行业都可以放进 `additional_asset`，**可以有很多列**。

和现在这份表一样即可：**第一行可以空着，从第二行开始**。第二行左边是「指标名称」，右边是各资产名字（Wind 常写成 `中际旭创(300308):收盘价(后复权)`，网页上会显示成 `中际旭创(300308)`）。第三行起是日期和收盘价。前复权、后复权都可以。空格子留空，不要填 0。历史尽量 3–5 年。

然后和平时一样重算（Windows）：

```bat
python update_all_data.py --skip-model
```

Mac 用 `python3`。算完强制刷新网页。因子暴露矩阵会在原来 12 行下面**多出新资产的行**。名字带「债」「转债」的会按债券处理（回归里带上信用因子）。

上证50、沪金这些已经在主表里的列，如果又写进 additional_asset，会被跳过，避免算两遍。

## 11. 改面板参数：panel_config.json

打开项目根目录的 **`panel_config.json`**，改完保存，再跑：

```bat
python update_all_data.py --skip-model
```

Mac 用 `python3`。然后强制刷新网页。

常用改法：

- **热力图从哪一年开始**：`heatmap.lf_start`（月频，如 `"2021-01"`）、`heatmap.hf_start`（周频，如 `"2021-01-01"`）
- **相关矩阵不要某个因子**：把名字放进 `heatmap.exclude_factors`，例如 `["地缘因子"]`
- **相关矩阵只看某几个**：填写 `heatmap.include_factors`，例如 `["增长因子", "通胀因子", "利率因子"]`
- **暴露窗口**：`exposure.rolling_window_weeks`（默认 260 周）、`sample_length_weeks`（默认 104）、`bootstrap_samples`（默认 3000）、`alpha_scale`（默认 0.5）
- **暴露不要某个因子**：`exposure.exclude_factors`，例如 `["流动性因子"]`
- **暴露只看某几个**：`exposure.include_factors`
- **某个资产强制不算某因子**：`exposure.asset_exclude_factors`，例如 `{"沪金": ["地缘因子"]}`
- **非债券也要信用因子**：把 `credit_only_for_bonds` 改成 `false`
- **滚动相关窗口、波动警报**：`heatmap.rolling_corr_months` / `rolling_corr_weeks`，以及 `alerts` 里的周数和 σ。这两类改完刷新网页就会变，不必重算；窗口和因子名单要重跑更新。

不要改字段名。文件开头的 `_readme` 也写了这些说明。

只改暴露窗口、因子名单时，不必整套重跑：

```bat
python update_all_data.py --only exposure
```

只改热力图起点或相关矩阵要显示的因子：

```bat
python update_all_data.py --only corr
```

## 12. 常见问题

**Q：能不能给我自己的资产算暴露，并显示在网页上？**  
A：能。做成 `additional_asset.xlsx` 放到项目根目录，第一行可以空、从第二行「指标名称」开始，见第 10 节。

**Q：我不是已经自己拉数据了吗？为什么还要跑 `update_all_data.py`？**  
A：你拉的是原料（PMI、金价）。网页要的是炒好的因子、矩阵、暴露。不跑这条命令，网页不会变。

**Q：模型失败了，图还会更新吗？**  
A：会。模型在最后。热力图和暴露只要前面几步成功，就已经写到硬盘上了。刷新网页即可。

**Q：报 `command not found: python`。**  
A：这台电脑上命令叫 `python3`。Windows 上则常常是 `python` 而不是 `python3`。

**Q：报找不到某一列，比如 `国开债_3Y`。**  
A：Excel 里缺这根 Wind 指标。按第 8 节把「中债国开债到期收益率:3年」加进去重新导出，覆盖 `data1.xlsx` 再跑。

**Q：相关矩阵从哪一年开始？**  
A：默认从 **2021 年**。要改的话打开 `panel_config.json` 里的 `heatmap.lf_start` / `hf_start`。

**Q：暴露矩阵右边的 R方是什么？为什么和旧版不完全一样？**  
A：现在显示的是 OLS R方（同一窗口、同一批因子的普通回归解释力）。格子里的系数仍是 Bootstrap + Lasso 中位数。算法和旧版 macro_quant 一样，但现在样本从约 2021 年才齐、默认 260 周，高频因子也换成了 Wind，所以数字会有差别。个股 R方低是正常的。详见第 6 节。

**Q：日频的高频因子表在哪？**  
A：项目根目录的 `hf_factor_daily.xlsx`（以及两个 csv）。每次跑 `update_all_data.py` 会自动再导一遍；只想重导这一张：`python3 export_hf_factor_daily.py`。

**Q：只改 `panel_config.json` 要跑哪一步？**  
A：改窗口/因子名单要重算。只改暴露：`--only exposure`。只改热力图：`--only corr`。滚动相关窗、波动警报阈值改完刷新网页即可，不必重算。

**Q：我能不能只算因子、不算模型？**  
A：能。`python update_all_data.py --skip-model`（Mac 用 `python3`）。

**Q：想先看看它打算跑哪几步、不真正算。**  
A：`python update_all_data.py --dry-run`

日常推荐流程就三句（Windows 示例）：

```bat
把新导出的表覆盖成 data1.xlsx
python update_all_data.py --skip-model
python -m http.server 8765
```

然后打开 <http://127.0.0.1:8765/macro_factor_corr_interactive.html> 并强制刷新。
